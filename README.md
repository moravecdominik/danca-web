Opraveno podle posledních připomínek:

- na mobilu je hlavní fotografie přímo v pozadí úvodní sekce,
- samostatná vysoká fotografie pod úvodem už nezabírá další prostor,

2. GitHub Desktop: Commit to main.

4. Cloudflare Pages web automaticky aktualizuje.
